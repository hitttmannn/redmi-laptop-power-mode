# Redmi Laptop Power Mode

[English](README.md) · [Русский](README.ru.md)

Апплет для панели Cinnamon, который показывает режим производительности **Redmi Book Pro 14 2022 (TM2107)**. Переключайте режимы штатным сочетанием **Fn + K** — значок обновляется автоматически.

![Индикатор с тремя делениями](assets/indicator-preview.svg)

| Ярких делений | Режим | Прежние PPT Fast / Slow | На зарядке (цикл проверен) |
|---|---|---|---|
| Одно | Экономичный | 30 / 10 Вт | 35 / 20 Вт |
| Два | Сбалансированный | 45 / 28 Вт | 60 / 50 Вт |
| Три | Производительный | 50 / 30 Вт | 65 / 54 Вт |
| Знак вопроса | Неизвестно | Нет свежих данных, ошибка чтения или незнакомые значения | — |

Наведите указатель на значок, чтобы увидеть название режима и ограничения мощности. Щелчок открывает меню. После Fn + K подождите около **10 секунд**. Числа показывают **ограничения мощности**, а не текущее потребление ноутбука. Режим определяется по двум ограничениям; другие программы настройки питания могут повлиять на результат.

## Что потребуется

- **Linux Mint 22.3**, рабочий стол **Cinnamon**. Разработка велась на Cinnamon **6.6.9** и ядре **7.0.0-38-generic**.
- Redmi Book Pro 14 2022 с моделью платы **TM2107**. На других платах сборщик намеренно не запускает RyzenAdj; другие модели Redmi не проверены.
- Python 3, systemd и **RyzenAdj**. RyzenAdj **не установлен в Linux Mint по умолчанию** и **не входит** в этот проект. Ниже объясняется, как его установить.

Если сомневаетесь в модели платы, выполните:

```sh
cat /sys/class/dmi/id/board_name
```

Ожидаемый результат — `TM2107`.

## Установка

### 1. Откройте терминал

Нажмите **Ctrl + Alt + T**. Команды можно вставлять сочетанием **Ctrl + Shift + V**, затем нажимать Enter. Выполняйте блоки по порядку. Если возникла ошибка, остановитесь и сохраните её текст.

Команды с `sudo` запрашивают права администратора. При запросе введите пароль своей учётной записи. Символы и звёздочки при вводе пароля не появляются — это нормально.

### 2. Установите RyzenAdj

Если `/usr/local/bin/ryzenadj` уже установлен и работает, пропустите команды сборки и выполните проверку в конце этого шага. Не заменяйте рабочую установку без необходимости.

Если RyzenAdj ещё нет, установите инструменты для его сборки:

```sh
sudo apt update
sudo apt install git build-essential cmake pkg-config libpci-dev python3
```

Скачайте исходники из официального репозитория, соберите программу от обычного пользователя и установите полученный исполняемый файл:

```sh
mkdir -p ~/redmi-power-mode-build
cd ~/redmi-power-mode-build
git clone --depth 1 https://github.com/FlyGoat/RyzenAdj.git
cmake -S RyzenAdj -B RyzenAdj/build -DCMAKE_BUILD_TYPE=Release
cmake --build RyzenAdj/build --parallel 2
sudo install -o root -g root -m 0755 RyzenAdj/build/ryzenadj /usr/local/bin/ryzenadj
```

Команды основаны на [официальной инструкции сборки для Linux](https://github.com/FlyGoat/RyzenAdj#build); `pkg-config` нужен согласно текущему [CMakeLists.txt](https://github.com/FlyGoat/RyzenAdj/blob/master/CMakeLists.txt). Если папка исходников уже существует, используйте другую пустую папку для сборки. Скачивается текущая версия проекта; будущие версии могут вести себя иначе.

Проверьте, что установленная программа читает ограничения мощности:

```sh
sudo /usr/local/bin/ryzenadj --info
```

Найдите строки **PPT LIMIT FAST** и **PPT LIMIT SLOW** с числами. Вместе с таблицей могут появиться диагностические сообщения. Если таблицы нет или доступ запрещён, остановитесь и сохраните полный вывод. Не меняйте права доступа к памяти, не отключайте защиту ядра и не устанавливайте дополнительный модуль только для обхода ошибки. Для RyzenAdj нужен доступ к оборудованию, который может быть ограничен системой.

Эта команда только запрашивает сведения; не добавляйте параметры изменения мощности. Отдельные службы автоматической настройки RyzenAdj для апплета не нужны.

### 3. Скачайте этот проект

На странице этого репозитория в GitHub нажмите **Code → Download ZIP** и распакуйте архив. Откройте полученную папку: в ней должны быть `collector.py`, `applet` и `systemd`. Щёлкните по пустому месту правой кнопкой и выберите **«Открыть в терминале»**.

Все оставшиеся команды установки выполняются в этом терминале. Если предпочитаете Git, вместо скачивания ZIP можно выполнить:

```sh
git clone https://github.com/hitttmannn/redmi-laptop-power-mode.git
cd redmi-laptop-power-mode
```

### 4. Установите апплет панели

«Апплет» — это небольшая программа на панели Cinnamon. Следующие команды создадут его папку и скопируют файлы:

```sh
mkdir -p ~/.local/share/cinnamon/applets/redmi-mode@local
cp -R applet/redmi-mode@local/. ~/.local/share/cinnamon/applets/redmi-mode@local/
```

Если команды ничего не напечатали, обычно это означает успешное копирование. Подсказки, меню и ошибки отображаются на языке сеанса: доступны русский и английский. Для остальных языков используется английский. Готовый перевод входит в папку апплета, отдельно устанавливать его не нужно. После смены языка системы выйдите из учётной записи и войдите снова.

### 5. Установите программу получения показаний

Сам значок работает от обычного пользователя. Отдельная фоновая служба читает показания оборудования и сохраняет их в файл для значка. Перед установкой можно изучить `collector.py` и два файла в папке `systemd/`.

```sh
sudo install -d -o root -g root -m 0755 /usr/local/libexec/redmi-mode
sudo install -o root -g root -m 0755 /usr/local/bin/ryzenadj /usr/local/libexec/redmi-mode/ryzenadj
sudo install -o root -g root -m 0644 collector.py /usr/local/libexec/redmi-mode/collector.py
sudo install -o root -g root -m 0644 systemd/redmi-mode.service systemd/redmi-mode.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl start redmi-mode.service
cat /run/redmi-mode/status.json
```

Успешный результат содержит **`"ok": true`** и поля `fast` и `slow` с числами. Если видите `"ok": false`, сначала воспользуйтесь разделом решения проблем.

### 6. Обязательно включите автоматическое обновление

Без этого шага первые показания устареют через 20 секунд и значок станет вопросительным.

```sh
sudo systemctl enable --now redmi-mode.timer
systemctl is-active redmi-mode.timer
```

Ожидаемый ответ — **`active`**. Обновление заработает сразу и после следующих включений ноутбука. Пароль при каждом обновлении не требуется.

### 7. Добавьте значок на панель

1. Откройте **«Системные настройки → Апплеты»**.
2. Найдите **«Redmi — Power Mode»** или **«Redmi — режим производительности»**.
3. Выберите его и нажмите **«+»**.
4. Подождите около 10 секунд. Нажмите Fn + K и подождите ещё раз для проверки.

Если апплета нет в списке, сохраните открытые документы, выйдите из учётной записи и войдите снова.

## Если появился знак вопроса

Наведите указатель на значок и прочитайте причину. Короткое ожидание после входа или пробуждения нормально.

**«Данные устарели»:** включите таймер и подождите около 10 секунд:

```sh
sudo systemctl enable --now redmi-mode.timer
systemctl is-active redmi-mode.timer
```

**«Сборщик не установлен…»:** выполните шаги 5 и 6. Если служба уже установлена, попробуйте `sudo systemctl start redmi-mode.service`.

**«Сборщик не получил PPT»:** соберите следующие сведения, чтобы передать их тому, кто помогает с настройкой:

```sh
cat /run/redmi-mode/status.json
systemctl status redmi-mode.timer redmi-mode.service --no-pager
sudo journalctl -u redmi-mode.service -n 30 --no-pager
```

Сообщение об отсутствии файла тоже сохраните. Пароли и SSH-ключи публиковать не нужно. Служба намеренно отбрасывает диагностический шум RyzenAdj. Если он нужен для поиска причины, остановите таймер, один раз выполните `sudo /usr/local/bin/ryzenadj --info`, затем снова запустите таймер. Избегайте частого одновременного опроса оборудования.

**Числа есть, но режим неизвестен:** оба ограничения должны соответствовать знакомому диапазону. Нажмите Fn + K, подождите и запишите два числа, если проблема осталась. Другая программа настройки питания могла изменить ограничения.

Пункт **«Обновить показания»** в меню перечитывает последний файл состояния. Он не выполняет новое измерение немедленно.

## Обновление апплета

Если меняется только значок, уберите апплет с панели, откройте терминал в папке новой версии проекта и повторите шаг 4. Затем добавьте апплет через настройки Cinnamon. Переустанавливать службу ради смены значка не нужно.

У службы отдельная копия RyzenAdj, принадлежащая администратору. Обновление `/usr/local/bin/ryzenadj` не заменяет эту копию автоматически. После проверки новой версии остановите таймер и службу, повторите команду копирования из шага 5 и запустите таймер. Для обновления сборщика или файлов службы остановите таймер и службу, повторите шаг 5, затем шаг 6.

## Приостановка и удаление

Приостановить автоматическое получение показаний:

```sh
sudo systemctl stop redmi-mode.timer
```

Когда последние данные устареют, значок покажет `?`. Возобновить:

```sh
sudo systemctl start redmi-mode.timer
```

Если просто убрать значок с панели, фоновая служба **продолжит работать**. Для полного удаления сначала уберите апплет с панели, затем выполните:

```sh
sudo systemctl disable --now redmi-mode.timer
sudo systemctl stop redmi-mode.service
sudo rm -f /etc/systemd/system/redmi-mode.service /etc/systemd/system/redmi-mode.timer
sudo systemctl daemon-reload
sudo rm -f /usr/local/libexec/redmi-mode/collector.py /usr/local/libexec/redmi-mode/ryzenadj
sudo rmdir /usr/local/libexec/redmi-mode
sudo rm -f /run/redmi-mode/status.json
sudo rmdir /run/redmi-mode
rm -r ~/.local/share/cinnamon/applets/redmi-mode@local
```

Исходная программа `/usr/local/bin/ryzenadj` и папка её исходников/сборки останутся, чтобы ими могли пользоваться другие инструменты.

## Доступ к оборудованию и проверка

Апплет сам не переключает режимы и не задаёт ограничения мощности. Системная служба выполняет одну фиксированную команду `ryzenadj --info` примерно раз в 5–8 секунд; значок читает файл показаний раз в 2 секунды. Установка не добавляет общих правил sudo, программ с setuid или прямых записей в EC. Получение телеметрии RyzenAdj всё же требует привилегированных запросов SMU: это **не строго пассивное чтение оборудования**.

На одном ноутбуке TM2107 подтверждены успешное чтение 30/10 Вт, работа таймера и загрузка апплета в Cinnamon. На зарядке проверен полный цикл Fn + K: 35/20 → 60/50 → 65/54 → 35/20 Вт. Полный цикл от батареи, автоматические переходы между зарядкой и батареей и сон/пробуждение ещё требуют приёмочной проверки. Автоматические тесты проверяют парсер и логику/чтение данных апплета, а не прошивку ноутбука.
